# Projekt: Osobní profil

## Popis projektu
Jednoduchý program v Pythonu, který vytvoří osobní profil uživatele.

## Funkce
- Získání jména uživatele
- Zjištění věku
- Zjištění oblíbené hry
- Výpočet věku za jeden rok
- Vypsání informací pomocí f-stringu

## Cíl projektu
Procvičit si základy Pythonu, proměnné, input(), print() a f-stringy.

## Technická část
Program je vytvořen v jazyce Python. Nepoužívá žádné externí knihovny ani API. Pro ukládání informací používá proměnné a pro výpis f-stringy.

## Očekávaný výsledek
Program vytvoří a vypíše osobní profil uživatele včetně jeho věku za jeden rok.
