# Osobni profil

## Popis projektu
Jednoduchy program v Pythonu, ktery vytvori osobni profil uzivatele.

## Funkce
- Ziskani jmena uzivatele
- Zjisteni veku
- Zjisteni oblibene hry
- Vypocet veku za jeden rok
- Vypsani informaci pomoci f-stringu

## Pouzite technologie
- Python
- Visual Studio Code

## Cil projektu
Procvičit si zaklady Pythonu, promenne, input, print a f-stringy.
